# 可视化与全应用 MCP 实施跟踪

## 用户要求

Excel 提供完整可视化分类、AI 辅助、UI 入口以及生成图片到 Word、Markdown、PDF 的共享。图形范围包含比较、占比、分布、关系、时序、层次、流向、地图、统计科研、文本、网络、科学可视化和指标；支持按数据类型筛选以及静态、动态、交互、仪表盘、大屏、信息图和故事呈现。

MCP 范围是整个 ZenOffice 的应用服务功能，包含 Word、Excel、PPT、PDF、Markdown、ArtFlow、AI、文件管理与跨模块共享，并非只暴露可视化工具。必须根据各模块实际操作逐项登记覆盖情况，并提供安装启动、客户端连接配置、参数与返回结构、调用实例和错误处理文档。

## 完成判据

每个图形必须有真实数据输入、正确的图形语义、可用的渲染与导出证据。科学和地理图形需校验体数据、坐标或地理边界，不能用常规图替代。每项应用服务必须有明确的 MCP 调用、错误行为及验证证据。仅目录、工具名称或空实现不构成完成。

## API 盘点工具

运行 `node tools/mcp-api-inventory.mjs /tmp/zenoffice-mcp-api-inventory.json`，从 TypeScript 接口（包括继承的方法）提取各模块的方法、参数、返回类型、注释和源代码位置。带回调的接口标记为需要订阅适配。清单中所有操作初始标记为 `not-implemented`，不能将盘点数量当作已实现 MCP 工具数量。编辑器内部命令和 ArtFlow 服务仍需补充盘点。

## 应用连接进度

本轮新增 AI 图表推荐、AI 审稿和 AI 编剧 MCP 工具，总计 38 项。图表推荐只向模型发送选定列并返回可直接再次渲染的 request。SVG 文件可经 images_insert 插入 PDF 当前页。Word/Markdown 审稿界面与 MCP 共用 review-runner，编剧共用固定版本技能和提示词；MCP 返回原稿版本用于后续冲突检查，不主动写回。编剧界面检测原稿变化后拒绝直接插入旧建议。中英文及双语 PDF 手册新增第 44–47 节，附可复制客户端配置示例。模型流程测试使用本地模拟服务，未验证真实远程模型质量。

分享列表在面板打开期间自动刷新，切回应用时立即刷新，新打开的文档不必关闭工作台后重选。未保存 Markdown 以 data URL 内嵌图片，已保存文档仍使用 assets 目录；序列化/重新解析保留内嵌图片。Excel 分享到 PDF 时发送 SVG，由 PDF 接收端栅格化后插入当前页，并切换至编辑选项卡、启用图片编辑；可移动、缩放和保存，暂不保留可编辑矢量路径。Office 其他模块仍接收 PNG。

Excel 数据可视化已加入三步引导：确认数据和允许使用的列、按分析目的选择本地或 AI 推荐图表、调整显示字段并查看真实数据预览。没有有效选区时可输入当前工作表范围。AI 仅接收勾选列的字段概况及前 30 行样本，返回结果通过完整数据校验后才可采用；用户确认后进入工作台，不修改源工作簿。也可跳过引导手动选择图表，或重新引导。AI 使用应用现有模型配置，未配置时仍可使用本地推荐。

引导的 3 项单元测试和 5 项桌面回归测试通过，覆盖范围输入、排除列不发送给 AI、推荐采用、字段调整、无效字段阻止生成、重新引导、手动图表及共享至 Word/PPT/Markdown/PDF。AI 响应通过模拟 IPC 验证，尚未验证真实远程模型。截图已检查，代码尚未发布。

等高线图支持完整矩形 X/Y/Z 网格（4–4096 点，可非等间距），5 个等间距等值级。采用 marching squares，边界交点线性插值，鞍点用双线性判别处理，恰好位于鞍点高度时保留交叉。重复或缺失网格报错，不插补散点，不外推。测试验证已知平面方程、闭合山峰、鞍点两种连通性及精确交叉；浏览器悬停验证等值级并检查图像。真实 Excel 测试验证 Y 坐标/高度字段入口、预览与 SVG 导出；AI 验证完整网格，MCP SDK 验证输出。最低画布 400×300。

圆形打包图使用 d3-hierarchy 的确定性布局，最多 300 个节点、12 层。复用层级校验；父权重自动汇总或验证一致性，零权重节点不占面积。叶子圆面积按权重成比例，父圆含空隙不能当作父权重面积比例。标签保持 14px，只在圆内或父圆顶部空白足够时显示；悬停显示完整路径和叶子权重/子节点合计。数值测试验证跨深度叶子面积比例、包含关系、兄弟圆不重叠、稳定排序及极端比例拒绝。实际浏览器验证文字边界与悬停，已检查图像；真实 Excel 验证父节点字段、工作台预览和 SVG 导出入口。AI 参数校验及 MCP SDK 输出验证通过。

地平线图支持 1–6 个同量纲系列、2–2000 个唯一时间点（数值或 YYYY-MM-DD 日期）。以零为基线，所有系列最大绝对值的三分之一为共同带宽；正数蓝色、负数橙色，各三层向上折叠，深色表示更大幅度。跨越零点/色阶边界时先插值再折叠；缺失值断开，重复时间报错，不自动汇总。数值测试验证分层幅度守恒、共用尺度、缺失值和极端正负数；浏览器验证悬停原始值、多行同步缩放和重置，已检查实际图像。导出宽度至少 640px，高度至少 160 + 70×系列数；UI 使用 960×600 预览。AI 校验覆盖采样外重复时间；MCP SDK 验证 SVG 输出。

六边形分箱图按归一化平面内固定六边形网格统计观测条数，重复点逐条计数，空箱留白，不将颜色解释为概率密度。两轴分别映射到 2×1 平面，半径 0.04；屏幕形状随画布纵横比例变化，箱归属和计数不变。完整数值配对校验覆盖 AI 采样之外的行；数值测试验证边界、计数守恒、输入顺序无关、常量轴与极端数值。浏览器测试验证悬停计数、改变画布尺寸及一万条观测的渲染；MCP SDK 调用验证 SVG 输出。

聚类树状图使用欧氏距离和平均连接法（UPGMA），支持 2–80 个样本、1–20 个完整数值特征，默认不标准化。纵轴表示合并距离，分支使用连续横坐标，保留簇中心的分数位置。测试验证已知合并距离、重复观测、缺失/溢出拒绝和实际坐标；图像已检查，浏览器悬停验证合并样本数。密集或长样本标签仍需更多布局验证。

词云使用提供的词语/频次，重复词语去除首尾空白后合并，零频词不显示，不自动分词。支持最多 80 个词语；统一字号尺度随画布空间调整，最小 16px，无法完整排布时明确报错。数值测试验证合并、确定性排布和碰撞；浏览器验证 40 个词语的实际文字边界无重叠、全部在画布内，并检查悬停频次。已检查实际图像，接入 Excel、AI 绑定说明及 MCP 目录/渲染。

力导向网络图使用确定性 Fruchterman–Reingold 布局，静态与交互初始坐标共用同一计算；距离不表示业务数值。重复有向边求和，箭头表示方向，线宽与权重成正比，布局吸引力不按权重调整。支持拖动和缩放；真实浏览器验证拖动后边权不变。当前最多 80 节点、500 条汇总边，暂不支持自连接（明确报错），密集标签仍需更多视觉验证。

弧形图已接入 Excel 字段选择、AI 绑定说明与 MCP 目录/渲染。按首次出现排列节点，重复有向边求和；上弧表示从左到右，下弧表示从右到左，圆环表示自连接。线宽与权重成正比，零权重保留节点但不画连接。数值测试验证方向与线宽，实际 SVG 已检查，浏览器真实悬停验证汇总权重。最多 30 节点、200 条汇总边，标签无法完整显示时要求筛选或放大尺寸。

已加入带令牌验证的 loopback 应用桥接及应用、项目/对话、知识库、图片共享、文本 AI、Word/Markdown 基础编辑工具。默认关闭，通过环境变量启用；stdio 与桌面端共享参数校验。图片共享等待目标编辑器确认，不主动保存文档。文本 AI 复用桌面配置和统一生成服务，支持取消；协议桥接取消传播已验证。其余编辑器功能、AI 与 ArtFlow 等服务仍待接入，完整功能覆盖尚未完成。
