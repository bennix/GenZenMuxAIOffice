GenOffice

让文档、表格与演示文稿，拥有同一个 AI 工作台。

一款独立的 macOS 办公应用。API Key 只保存在本机；文本生成与 PPT、Word 配图统一通过 ZenMux 调用。

下载 macOS DMG ↓
Apple Silicon · macOS · Developer ID 签名与 Apple 公证
01

本地优先

ZenMux API Key 在设置页加密遮罩显示，并永久保存在当前 Mac。

02

真正的办公文件

在一个应用中处理 Word、Excel、PowerPoint、PDF 与 Markdown。

03

AI 原生配图

PPT 默认生成 16:9 横图，Word 默认生成 3:2 配图，并可自定义图像模型。

04

公式与表格

Word、PPT、Excel、Markdown 支持 LaTeX、多行公式及截图识别；可从剪贴板或文件插入。

05

严格 AI 审稿

3 名委员与 1 名主席联合审阅正文、公式、表格、图片、图表和图形，可输出中英文报告。

06

网络提示

AI 功能依赖网络；网络或代理状态可能影响可用性、速度与生成结果。
