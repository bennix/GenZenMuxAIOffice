01

本地优先

ZenMux API Key 在设置页加密遮罩显示，并永久保存在当前设备。

02

真正的办公文件

在一个应用中处理 Word、Excel、PowerPoint 与 Markdown。

03

AI 原生配图

PPT 默认生成 16:9 横图，Word 默认生成 3:2 配图，并可自定义图像模型。

04

公式与表格

Word、PPT、Excel、Markdown 支持 LaTeX、多行公式及截图识别；可从剪贴板或文件插入。

05

严格 AI 审稿

3 名委员与 1 名主席联合审阅正文、公式、表格、图片、图表和图形，可输出中英文报告。

06

@Connect 信息通路

把 AI 回复本地发送到另一个 Word、Excel、PPT 或 Markdown 标签，并保持内容可编辑。

07

Markdown 选区 AI 锚点

选中文字后可直接提问、精确改写，或在选区前后插入可编辑的 AI 内容；发送时固定锚点，并阻止过期选区误写。

08

AI 回复公式实时渲染

Word、Excel、PPT 与 Markdown 的 AI 回复统一使用 KaTeX；支持行内、独立、多行公式，以及列表、粗体和表格中的公式。

09

PPT 录制与 MP4

“幻灯片放映”和“插入”选项卡均可直接开始录制；macOS 将麦克风与 GenOffice 演示文稿内播放的媒体声音混合，Windows 还支持系统声音；支持暂停、继续和本地 MP4 导出。视频在编辑预览和放映中按插入位置与尺寸播放，并保持原始宽高比。

10

媒体与图片拖放

视频、音频可直接拖到 PPT 指定位置；图片可拖入 PPT、Word 与 Markdown，插入后仍可移动、缩放和编辑。

11

Word 图片完整环绕

支持嵌入、四周、紧密、穿越、上下、衬于文字下方及浮于文字上方；图片可移动、等比缩放并使用位置预设，保存为原生 DOCX 布局。

12

AI 扫描件修复

通过 ZenMux 的 openai/gpt-image-2 去除手写痕迹或增强黑白扫描件；提供处理前后预览，确认后才替换原图。AI 结果需人工核对并可能受网络影响。

Upstream & adaptation · 项目来源与改造

源自 GenOffice，
面向 ZenMux 深度改造。

本项目是 genspark-ai/genoffice ↗ 的衍生版本，遵循原项目 Apache-2.0 许可证。我们保留其 Office 编辑器基础，并在此之上完成以下适配与增强。

01

AI 全面切换 ZenMux

Word、Excel、PowerPoint、Markdown 的对话、写回、公式识别和配图统一走 ZenMux，不依赖 Genspark 登录。

02

隐私与模型设置

API Key 经系统凭据服务加密后永久保存在本机；设置页支持遮罩显示、预置模型及自定义模型。

03

内容与学术能力增强

新增选区上下文、附件、联网核查、AI 审稿委员会、翻译、LaTeX、公式图片识别，以及 AI Mermaid 生成与修改；Markdown 选区支持问答、精确回填和前后锚点插入。

04

编辑与数据能力增强

加强可编辑 PPT、Markdown 与 Word 转换、Excel 分析和可视化、艺术字与绘图形状，并支持双向复制 AI 消息源文。

05

独立桌面发行

重新构建 macOS 与 Windows 安装包；macOS 使用 Developer ID 签名并经 Apple 公证，同时维护 GitHub Release 与下载页。

06

适配与维护署名

AI 适配与修改由复旦大学计算与智能创新学院徐志平完成，并持续同步安全修复与跨平台发布。

Complete capability atlas · 完整功能图鉴

五个工作台，
一套完整办公系统。

ZenMux intelligence layer

AI 不只回答，
它直接理解并修改文件。

所有文档、表格、演示、Markdown、公式识别和配图 AI 都统一通过 ZenMux；不再依赖 Genspark 云端账号。

01 · 选择上下文选择 Word 段落、Excel 单元格、PPT 对象或 Markdown 片段；未选择时可读取全文。
→
02 · ZenMux 推理使用本地保存的 API Key 和用户指定模型，结合附件、当前系统时间与可信网络来源完成推理。
→
03 · 写回可编辑文件内容直接写入真实 Office 对象，保留结构，并提供版本快照、撤销和回退。
文档内 AI 编辑撰写、润色、总结、翻译、排版、改写选区和结构化写回。
最多 5 个附件文件和图片附件、缩略图、拖放、文件选择与剪贴板图片。
公式视觉识别从截图、剪贴板或图片文件识别 LaTeX，并插入 Word、PPT、Excel 和 Markdown。
AI 图像生成PPT 与 Word 配图经 ZenMux 图像模型生成，并按文档比例适配。
严格审稿委员会至少 3 名委员加主席，多模型随机分配，针对不同期刊和标书标准。
互联网事实查证参考当前系统时间，并可查询主流媒体、Science、Nature、PubMed 等可信来源。
科研文献检索与引用Word、PPT、Markdown 可查询公开学术索引，导入通用文献格式，区分预印本，并插入可编辑引用和参考文献表。
自定义模型设置页可增加模型名称并永久保存，适配 ZenMux 新模型。
双向消息复制提示词与 AI 回复均可复制，并保留 Markdown、LaTeX、Mermaid 和代码块源文。
网络状态提示明确告知用户 AI 会受网络、代理、服务状态和模型可用性影响。
