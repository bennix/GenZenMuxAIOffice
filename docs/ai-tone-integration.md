# Word / Markdown 表达风格检查

入口：编辑器顶部“AI 检测 / 去 AI 味”。本功能检查表达特征，不鉴定作者身份。

## 本次实际接入

- 原有 lieflat-less-ai-tone：固定版本 27d29232f10124db904ca9c0536d0b67cb3b2833，MIT，保守校订默认模式。
- no-ai-slop-zh：参考固定版本 89d6fab9079bb249c25a254924c418885e964d34，MIT，改编为中文自然表达模式及有限离线词句规则。不是完整运行上游 Skill；应用的事实、格式保护和逐条确认优先。
- 应用自有英文简洁表达规则：有限短语扫描及 AI 编辑指令，没有捆绑第三方英文检测器。

离线扫描不发送正文；“检测并去 AI 味”仍调用用户配置的 AI。可另选“当前 AI 复核”进行语境判断。前后使用相同检测方式和规则，改变选项会清除旧结果；改变所选修改后必须重新检测才能应用。

规则命中占比 = 命中的非空白字符数 / 可处理的非空白字符数。重叠只计一次。它不是 AI 生成概率，也不是商业检测器分数；专业词汇、正常对比、标点均可能误报。代码、链接、引用块和嵌入对象不参与处理。按编辑器文字格式片段扫描，跨格式边界的短语可能漏报。
