# ZenOffice v0.6.70

## 个人知识库界面重设计

- 将个人知识库设置重构为清晰的本地记忆控制台。
- 新增“仅存本机”隐私状态提示，明确完整知识库不会上传。
- 使用紧凑开关取代原生复选框，并补充每项设置的用途说明。
- 将单次引用数量改为可访问的步进器，范围限制为 1–10 条。
- 重新设计搜索栏、结果数量、记忆卡片、删除操作与空结果状态。
- 移除结果列表的嵌套滚动，避免内容和底部操作按钮被遮挡。
- 同步完善中英文界面与键盘焦点反馈。

## Personal knowledge UI redesign

- Rebuilt Personal Knowledge as a focused local-memory control panel.
- Added a clear local-only privacy indicator.
- Replaced native checkboxes with compact, accessible switches and explanations.
- Added a bounded stepper for controlling memories retrieved per request.
- Refined search, result counts, memory cards, deletion controls, and empty states.
- Removed nested scrolling that could clip results and footer actions.
- Improved bilingual copy and keyboard focus behavior.

The core ZenMux-powered Word, Excel, PowerPoint, Markdown, PDF, AI review, local RAG, and @Connect workflows remain available.
