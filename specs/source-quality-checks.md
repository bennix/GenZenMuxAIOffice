# 源码质量检查

规则：未被读取的提示词常量应删除；Playwright 无 fixture 的测试回调使用 `_fixtures` 参数，不使用空解构。此清理不改变布局判断或打印行为。

状态所有者与接口：保持既有布局判断函数及 Playwright fixture 接口，测试参数占位不产生状态。

验收：全仓 `npm run lint` 无错误，相关布局判断测试与全仓类型检查通过。已有警告如实报告。

## E2E 文档隔离

测试启动器不只隔离 userData，也必须将 defaultSaveDir 指向其临时 userData/drafts。生成草稿不得落入真实 Documents/ZenOffice。重复启动保留测试配置，既有测试默认目录设置不被覆盖。可通过环境传入真实样例作验证，但先复制到临时目录；输出只在验收成功后复制到显式指定的新路径。验收检查原稿页数与输出一致、原生文字对象存在，绝不将测试文字当作用户成品。
