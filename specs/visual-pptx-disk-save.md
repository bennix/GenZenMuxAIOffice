# 保真 PPTX 磁盘保存确认

产品规则：完成 OfficeCLI 校验与原子发布后，必须重新从最终目标路径读取文件，确认非空、普通文件且内容哈希与临时已验证 PPTX 一致，才返回成功。返回实际绝对路径（解析符号链接），不把用户请求路径当作成功证据。成功后主进程在系统文件管理器中定位文件，状态栏显示同一实际路径；定位失败不撤销已完成的保存。

所有者：officecli-visual-export 唯一负责创建/校验/发布/磁盘确认；slides-main 负责 IPC 与系统文件管理器操作，renderer 只显示结果。不改 PDF、可编辑保存或导出页内容。

事件：renderer 选路径 → 渲染 → main OfficeCLI 构建 → 校验 → 原子 rename → 读取最终文件并比较 → 返回实际路径/定位文件。任何确认失败返回错误，不能显示“已保存”。

验收：真实 CLI 写入中文含空格路径、文件字节与 PPTX 验收匹配；成功返回可读取路径；空输入失败且原目标不变。未运行实际桌面 UI 或 WPS 时不得声称通过。
