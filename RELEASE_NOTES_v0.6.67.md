# ZenOffice v0.6.67

This release introduces the new **ZenOffice** product identity across the desktop suite, installers, documentation, and website.

## Highlights

- New ZenOffice logo and unified dark-ink, mint-green, ivory, and amber visual system.
- Product naming updated across Word, Excel, PowerPoint, PDF, Markdown, settings, onboarding, update UI, native menus, permission prompts, and PDF metadata.
- New platform assets generated from one vector master: macOS ICNS, Windows ICO, and high-resolution PNG icons.
- Landing Page, README, GitHub issue templates, feature monograph, and user-manual sources updated to ZenOffice.
- New installer names: `ZenOffice-0.6.67-arm64.dmg`, `ZenOfficeSetup-0.6.67-x64.exe`, `zenoffice_0.6.67_amd64.deb`, and `zenoffice-0.6.67.x86_64.rpm`.
- Existing app IDs, Linux package ID, encrypted settings, document history, internal font aliases, and workbook metadata remain compatible with earlier GenOffice releases.
- On first packaged launch, an empty ZenOffice profile automatically imports an existing GenOffice or AI Office profile.

## macOS

The Apple Silicon DMG is signed with Developer ID and notarized by Apple. The notarization ticket is stapled to both the app and DMG.
